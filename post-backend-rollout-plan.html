Milestone 1: The Hosted Login Web App (login.endlessdomains.io)

The backend exposes the OIDC APIs, but players need a visual, branded interface. This is a dedicated Next.js web application deployed to its own subdomain (login.endlessdomains.io).

The 4 Player Screens to Build

WEEK 1 · FRONTEND
Screen 1: Game Info & Wallet Connect

Displays the calling game's name and logo (e.g. "Endless Vault wants you to sign in"). Reuses Reown AppKit to connect MetaMask, Coinbase Wallet, or scan a phone QR code via WalletConnect.

Screen 2: SIWE Signature Prompt

Prompts the wallet to sign the standardized EIP-4361 text message on Polygon (Chain ID 137). Completely free, 0 gas fees.

Screen 3: .og Domain Selector

Lists the wallet's verified domains with the player's PRIMARY reverse-record domain first (e.g., akshat.og). If the user has no domain, presents a Wallet-Only option and a button to buy an .og name.

Screen 4: Consent & postMessage

Shows the approved scopes (domain, address, avatar). Clicking Approve issues the authorization code, sends it to the game via window.opener.postMessage, and closes the popup.

🏁 Milestone 1 Exit Gate: An end-to-end manual test where a developer clicks "Sign In", connects MetaMask on stage, signs the message, picks akshat.og, and sees the popup close with the code delivered.

Milestone 2: The Client SDK Packages & CDN Distribution

Game developers will not write raw OIDC HTTP queries. We publish a clean, lightweight monorepo repository (endlessdomains-login-sdk) with two npm packages and a CDN script build.

The Two NPM Packages

WEEK 2 · SDK & TOOLS
1. @endlessdomains/login (<15KB gzip)

The browser SDK for game frontends:

  • Generates PKCE code_verifier and code_challenge.
  • Manages popup window and listens for postMessage.
  • Detects popup blockers and falls back to full-page redirect.
  • Automatically schedules token refresh before 1-hour expiry.
  • Includes ready-made branded button: login.renderButton().
2. @endlessdomains/login-verify

The backend verifier for game servers:

  • Fetches and caches /.well-known/jwks.json public keys.
  • Verifies ES256 signatures on player ID tokens offline in <1ms.
  • Validates audience, issuer, expiration, and pairwise sub.
  • Compatible with Node.js, Express, Cloudflare Workers, and Next.js.

10-Line Integration Experience for Game Studios:

import { EndlessLogin } from '@endlessdomains/login';

const login = new EndlessLogin({
  clientId: 'space-runner',
  redirectUri: 'https://spacerunner.game/callback',
  mode: 'popup' // or 'redirect'
});

// One line to authenticate
const player = await login.signIn();
console.log(`Verified Player: ${player.name} (${player.walletAddress})`);
// player.name = "akshat.og"
// player.domain_status = "owned"
🏁 Milestone 2 Exit Gate: Both packages published to a private or staging npm registry; bundle size verified under 15KB gzip; sample HTML test page signs in using the CDN script.

Milestone 3: Live Pilot Integration in Endless Vault

The best proof of an SDK is integrating it into our own production game: endless-vault_14 1.html. This proves the system end-to-end before asking external partners to adopt it.

The Endless Vault Transformation

WEEK 3 · GAME PILOT
Game Code Updates in endless-vault_14 1.html:
  • Delete the unverified text box #idIn and unverified status label #whoTag.
  • Embed the official "Sign in with your domain" button in the top HUD.
  • On sign-in, bind the player's mech to claims.name (e.g. akshat.og).
  • Trigger the Tier 3 Gold Halo Armor transformation, engraved plating, and golden lightning bolts.
Multiplayer & Leaderboard Integrity:
  • When submitting high scores, the game attaches the player's signed ID Token.
  • The leaderboard backend uses @endlessdomains/login-verify to confirm that the submitter genuinely owns akshat.og.
  • Cheated or spoofed high scores become mathematically impossible.
🏁 Milestone 3 Exit Gate: 5 internal team members play Endless Vault on both desktop and mobile; median login time is under 30 seconds; the leaderboard accurately reflects verified .og owners.
